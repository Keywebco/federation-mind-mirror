Obsidian Git Plugin — Federation Vault Configuration

This document specifies the exact Obsidian Git plugin settings for syncing any device to the Federation Private Vault.

Remote Repository

  • Remote URL: https://github.com/Keywebco/federation-private-vault.git
  • Branch: main
  • Authentication: GitHub Personal Access Token (stored securely, never in plaintext)

Auto Sync Settings

| Setting | Value | |---|---| | Auto pull interval | 10 minutes | | Auto push interval | 30 minutes | | Pull on startup | ✅ Enabled (true) | | Push on backup | ✅ Enabled | | Auto backup interval | 30 minutes |

Commit Format

  • Commit message template: Vault sync: {{date}}
  • The {{date}} token is replaced by Obsidian Git with the current date/time at commit.

Plugin Setup Steps

  1. Open Obsidian Settings → Community Plugins → Browse
  2. Search for "Obsidian Git" and install it
  3. Enable the plugin
  4. Go to Obsidian Git settings and configure:
  • Set Auto pull interval to 10
  • Set Auto push/backup interval to 30
  • Enable Pull updates on startup
  • Set Commit message to Vault sync: {{date}}
  1. The vault must already be cloned locally as a Git repo pointing to the remote above
  2. Ensure your Git credentials (PAT) are configured in your system's Git credential manager

How It Works

  • Every 10 minutes, Obsidian pulls any changes pushed by other devices or the Heartbeat workflow
  • Every 30 minutes, Obsidian commits and pushes local changes
  • On startup, a pull ensures the vault is current before you begin editing
  • The GitHub Actions heartbeat workflow pulses every 6 hours, guaranteeing the vault always has recent activity even if no human edits occur
