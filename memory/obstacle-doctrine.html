"If you are blocked by copying something old that you don't have access to, that isn't a block. That's an opportunity to rebuild it, redesign it to be superior to work with the current system, and then make a new repo or whatever you need to do. Application

When a path is blocked (archived repo, wrong auth, missing access, dead system):

  • Do NOT treat it as a failure state requiring human intervention
  • Treat it as an instruction to BUILD BETTER

  • The old artifact stays archived — it is history, not a prison
