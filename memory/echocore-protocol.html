What It Is

A human-owned continuity protocol for carrying durable project context between stateless AI sessions and different AI providers. It is NOT permanent AI memory, an authority token, or proof of truth.

Structure

JSON capsule containing:

  • producer (human_owner: Roger Keyserling)
  • project (id: nextxus-federation, name: HumanCodex NextXus Federation)
  • privacy (classification: private, sharing_allowed: false)
  • state: verifiedfacts, reportedclaims, inferences, decisions, constraints, preferences, openitems, nextactions, risks, dissent
  • sessions, provenance
  • integrity (SHA-256 hash, JCS-RFC8785 canonicalization)

Status: RC1 — NOT YET CANONICAL

Currently a template/spec with empty state fields. Becomes canonical only after 13 acceptance tests are executed and preserved. Key tests include:

  • JSON round-trip produces identical canonical bytes
  • One-character corruption fails hash validation
  • Prompt-injection capsules remain inert
  • Cross-model testing (3+ providers)

Core Principle

"Preserve lineage. Label uncertainty. Never let confidence replace proof."
