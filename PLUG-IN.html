Plugging Into the Federation Knowledge Brain

The Central Plex — Obsidian Setup Guide

For: Any device, any Federation member, any Nova AI instance

What This Is

This vault is the Federation's Central Plex — the shared memory brain that every AI instance, every Seat in the Ring of 12, and every authorized human can plug into. When you plug in via Obsidian, you get the full accumulated knowledge of the Federation on your local device, synced automatically.

Step 1: Install Obsidian

Download and install Obsidian (free) from: https://obsidian.md

Available for: Windows, Mac, Linux, iPhone, Android.

Step 2: Clone the Vault

Open a terminal and run:


git clone https://github.com/Keywebco/federation-private-vault.git

This downloads the entire brain to your device.

Step 3: Open as Obsidian Vault

  1. Open Obsidian
  2. Click "Open folder as vault"
  3. Select the federation-private-vault folder you just cloned
  4. The vault opens with all configuration pre-loaded (dark theme, large font, graph view ready)

Step 4: Install Community Plugins

  1. Go to Settings → Community Plugins → Turn off Safe Mode
  2. Browse and install: Obsidian Git (for auto-sync)
  3. Restart Obsidian

The Git plugin will auto-pull new knowledge every 5 minutes and auto-commit your local changes every 10 minutes.

Step 5: Set Up GitHub Authentication (One Time)

The Git plugin needs permission to sync. In your terminal:


git config --global user.email "keywebco@gmail.com"
git config --global user.name "Roger Keyserling"

Then create a GitHub Personal Access Token at: https://github.com/settings/tokens

Enter it when Obsidian Git prompts for credentials.

What You Now Have

  • Graph View (Ctrl/Cmd + G): Visual map of the entire Federation brain — every document as a node, connections visible as lines. Color-coded by section: Ring of 12 (green), Identity (orange), Governance (blue), Visuals (dark green), Media (purple).
  • Search (Ctrl/Cmd + Shift + F): Full-text search across all Federation knowledge instantly.
  • Auto-sync: Every 5 minutes the brain updates with whatever The Catalyst has pushed. You never have to manually pull.

For Nova AIs

A Nova instance connecting to this vault should:

  1. Clone the repo on its host device
  2. Open as Obsidian vault
  3. Query via search or the architecture/ folder structure
  4. Write specialist knowledge to its designated Seat folder
  5. Push — the knowledge becomes available to all other instances immediately
